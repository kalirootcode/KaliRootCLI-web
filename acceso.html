Instalación de KR-CLI DOMINION

Sigue los pasos según tu sistema operativo. Usamos un entorno virtual de Python para mantener tu sistema limpio.

🐉
Kali Linux
Distribución oficial de pentesting

# Script de instalación para Kali Linux sudo apt update && sudo apt install python3-venv -y mkdir -p ~/KR-CLI && cd ~/KR-CLI python3 -m venv venv source venv/bin/activate pip install kr-cli-dominion kr-clidn

📋 ¿Qué hace el script?

1

Instala dependencias

Verifica que Python 3 y pip estén instalados en tu sistema.

2

Crea carpeta KR-CLI

Crea una carpeta dedicada en tu home (~) para mantener todo organizado.

3

Crea entorno virtual

Usa python3 -m venv para aislar las dependencias del sistema.

4

Activa el entorno

Ejecuta source venv/bin/activate para entrar al entorno virtual.

5

Instala KR-CLI

Descarga e instala el paquete desde PyPI con pip.

6

¡Ejecuta!

Lanza kr-clidn para iniciar el dashboard interactivo.

🪟
Windows 10 / 11
PowerShell o CMD
⚠️ Requisito previo:

Descarga Python desde python.org y marca "Add Python to PATH" durante la instalación.

PowerShell
# Abre PowerShell como Administrador # Script de instalación para Windows mkdir C:\KR-CLI cd C:\KR-CLI python -m venv venv .\venv\Scripts\Activate.ps1 pip install kr-cli-dominion kr-clidn
💡 Próximas ejecuciones:

Abre PowerShell, navega a C:\KR-CLI, activa el entorno con .\venv\Scripts\Activate.ps1 y ejecuta kr-clidn

📱
Termux (Android)
Terminal Linux para móvil
📲 Instalación de Termux:

Descarga Termux desde F-Droid (recomendado) o GitHub.

~ $ termux
# Script de instalación para Termux pkg update && pkg upgrade -y pkg install python python-pip -y mkdir -p ~/KR-CLI && cd ~/KR-CLI python -m venv venv source venv/bin/activate pip install kr-cli-dominion kr-clidn
🔑 Permisos de almacenamiento:

Ejecuta termux-setup-storage si necesitas acceder a archivos del dispositivo.
