Bienvenido a KR-CLI DOMINION

Para acceder a la plataforma educativa completa, necesitas instalar KR-CLI y crear una cuenta.

1

📥 Instala KR-CLI

Ejecuta en tu terminal (Kali Linux, Parrot OS, o Termux):

pip install kr-cli-dominion

2

🚀 Inicia el programa

Ejecuta el comando para iniciar KR-CLI:

kr-clidn

3

📝 Crea tu cuenta

Regístrate dentro del programa con tu email. Recibirás 5 créditos gratis para empezar.

4

🔓 Accede a la web

Una vez registrado, inicia sesión aquí para acceder a cursos, laboratorios, noticias y herramientas.
