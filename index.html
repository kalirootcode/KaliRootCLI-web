⚔️ VECTORES DE ATAQUE

Conoce las técnicas que usan los atacantes. El conocimiento es tu mejor defensa.

🌊

DDoS Attack

Distributed Denial of Service. Saturación masiva de recursos mediante miles de solicitudes simultáneas desde múltiples orígenes. Colapsa servidores, redes y servicios haciéndolos inaccesibles. Vectores: UDP Flood, SYN Flood, HTTP Flood, Amplification attacks.

PELIGRO: CRÍTICO
📄

PDF Weaponizado

Exploits embebidos en documentos. PDFs aparentemente legítimos que contienen JavaScript malicioso, exploits de buffer overflow o enlaces de phishing. Se activan al abrir el documento. Bypass de antivirus mediante ofuscación y técnicas de evasión.

PELIGRO: ALTO
🎣

Phishing Avanzado

Ingeniería social automatizada. Réplicas exactas de sitios legítimos, emails spoofing con SPF bypass, y ataques de spear-phishing personalizados mediante OSINT. Credential harvesting en tiempo real con proxies inversos y MFA bypass.

PELIGRO: ALTO
💉

SQL Injection

Manipulación de bases de datos. Inyección de código SQL malicioso en formularios y parámetros. Permite extracción de datos, bypass de autenticación, escalación de privilegios y ejecución de comandos. Variantes: Blind SQLi, Time-based, Union-based, Error-based.

PELIGRO: CRÍTICO
🔥

Cross-Site Scripting

Inyección de scripts en navegador. Código JavaScript malicioso ejecutado en contexto de víctima. Robo de cookies/sesiones, keylogging, defacement, distribución de malware. Tipos: Reflected XSS, Stored XSS, DOM-based XSS, Blind XSS.

PELIGRO: MEDIO-ALTO
👁️

Man-in-the-Middle

Intercepción de comunicaciones. Posicionamiento entre víctima y servidor para capturar, modificar o inyectar tráfico. Técnicas: ARP Spoofing, DNS Poisoning, SSL Stripping, Evil Twin AP. Captura de credenciales, tokens y datos sensibles en tránsito.

PELIGRO: CRÍTICO
